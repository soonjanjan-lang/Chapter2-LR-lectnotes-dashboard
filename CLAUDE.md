# CLAUDE.md: Chapter 2 LR Lecture-Notes Dashboard

## What this project is
An interactive, tabbed teaching dashboard on **the Literature Review (Chapter 2) of a PhD thesis**. It was built for a PhD-level research methods course in economics at **Universiti Utara Malaysia (UUM), semester A261**. The course lecturer projects it in lectures, and students use the same public URL for self-study.

- Live site: https://soonjanjan-lang.github.io/Chapter2-LR-lectnotes-dashboard/
- Repo: https://github.com/soonjanjan-lang/Chapter2-LR-lectnotes-dashboard (public, branch `main`, GitHub Pages from `/`)
- Prompt history: `PROMPT_LOG.md`. **Append every new user prompt verbatim, and their answers to any clarifying questions, as a new dated entry at the bottom. Never edit or delete earlier entries.**

## Architecture (static site, no Node/bundler)
```
index.html                ← GENERATED by build.ps1. Do not hand-edit; edit src/ instead
src/shell.html            ← <head>, header, tab bar, footer; {{SECTIONS}} placeholder
src/sections/NN-*.html    ← one partial per main tab; assembled in filename order
build.ps1                 ← assembles index.html (UTF-8, no BOM)
assets/css/tokens.css     ← design tokens (colour, type, spacing, radius, shadow, motion) + dark theme
assets/css/base.css       ← reset, typography, layout, print
assets/css/components.css ← tabs, cards, callouts, tables, reveal, quiz, tools, diagrams
assets/js/app.js          ← routing (#/tab/sub), ARIA tabs + keyboard, theme, presenter mode, search, progress, copy buttons, mind maps, Lottie
assets/js/tools.js        ← interactive tools (roadmap, Boolean builder, scorecard, quizzes, checklists, decision tree, matrix builder, prompt library and builder, slop list and scanner, downloads)
assets/js/data/prompts.js ← the 18 prompts (window.LR_PROMPTS); {{slots}} are filled by the builder
assets/js/data/slop.js    ← slop lexicon and scanner samples (window.LR_SLOP)
assets/js/data/quizzes.js ← quiz banks: journals, apa, gaps, frameworks (window.LR_QUIZZES)
assets/lottie/animations.js ← the hero "literature funnel" Lottie, built in JS (window.LR_LOTTIE); layer classes lt-* are recoloured by CSS
(downloads)               ← no files: CSV templates, prompt pack and note template are generated in the browser by tools.js ([data-download] buttons)
source-notes/             ← lecturer's original .docx/.pdf notes (reference only)
```
**Build:** `powershell -ExecutionPolicy Bypass -File .\build.ps1`, then open `index.html`, or use the deep link `index.html#/search/scholar`.

### Section partial conventions
- Each partial is one `<section class="tab-panel" id="tab-<slug>" data-title="…" data-icon="…">` containing sub-panels `<article class="sub-panel" id="<slug>--<sub>" data-title="…">`.
- The sub-tab bars and the main tab bar are **generated by app.js** from these data attributes. Do not hand-write the nav.
- Reusable blocks (all styled in components.css):
  - Callouts: `.callout.callout--example | --worked | --pitfall | --teach | --try | --key | --ai`
  - Reveal: `<details class="reveal"><summary>Reveal model answer</summary>…</details>`
  - Bad/good pair: `.compare` with `.compare__bad` and `.compare__good`
  - Copyable prompt: `<div class="prompt" data-copy>…</div>`
  - Data tables: `.table-wrap > table.data`

## Content rules (important)
1. **British English** spelling (analyse, behaviour, programme, organisation).
2. **APA 7th** citations: `(Becker, 1968)`, `Becker (1968)`, `(Grubel & Scott, 1966, p. 270)`.
3. **Never fabricate real-looking citations.** Real works cited must be verified. Invented illustrations use **obviously fictional authors marked with †** (e.g., "Author A (2021)†"), with a note explaining that † marks fictional examples.
4. **The dashboard must not contain the AI-writing "slop" it teaches students to avoid.** Before committing, run the self-audit below. Specifically avoid: delve, tapestry, testament, pivotal, realm, intricate, multifaceted, underscore (as a verb), showcase, "navigate the complexities", "in today's fast-paced world", "it is important to note", and "plays a crucial role". The lexicon itself, inside the slop tab and `assets/js/data/slop.js`, is the only exception.
5. Do not label any real, named journal as predatory. Use hypothetical case cards.
6. Do not paraphrase UUM policy unless it is verified from an official UUM source. Link to it instead.
7. Economics examples should span several fields (labour, development, energy/environment, health, education, public, Malaysian policy).
